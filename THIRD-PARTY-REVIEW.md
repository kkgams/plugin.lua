The branch candidate and tagged release jobs both run `scripts/test-runtime-component.sh`, using the locked standalone `runtime-e2e/` Wasmtime 44 host to exercise the **final notice-bearing component** (main result, `host.call` bridge, syntax-error diagnostic) before they may upload or publish. This test passed locally; hosted Linux evidence is still required. Do not bypass the gate by treating the source/WIT checks as runtime coverage. Owner review of the exact `NOTICE`, hosted Linux map and candidate is also required before enabling repository digest variables or pushing public source.
